      Coordinate-triggered routines
      
Coordinate sequence is stopped. Feed drone positions before starting.

      
      
      
      
      

        
        
        
        
      

      
Start authorizes automatic arming at each next point. Its routine runs once when inside the radius, then the sequence advances. Position loss stops the sequence and output. Restart explicitly starts again at point 1.

      
Bluetooth GPS works with a connected phone or GPS controller. Wi-Fi GPS works with a drone telemetry bridge. Updates must stay fresh throughout the routine.

      
      
      

        
        
      

      
Select a MAVLink source and save the sequence first. For Bluetooth, connect BLE too. Send a position before Start, then edit it to test entering a radius. Test positions can run an enabled sequence; Stop sequence ends the feed and output.
