Routine library & custom steps

START_WAIT:ms is allowed only first and runs once. WAIT:ms runs every repeat. Other steps: WAIT_IDLE, DISPENSE:ms, or COMMAND followed by an allowed hardware command. Motor example: COMMAND:DEG:5,90,1

Coordinate-triggered routines

Start sequence enables automatic arming at each next point. The sequence stops if aircraft position is more than 3 seconds old. Outputs disarm between points. Always use STOP ALL to cancel.

Up to 500 points; radius 0.1–1000 m. Paste one point per line to import a larger plan. Only the next point can trigger. Known accuracy must fit its radius. Use the aircraft's position feed; this console does not use your phone's location.

Self-test, indicators & boot policy
Checks exercise configuration, storage and inactive controls. Physical motion and radio transitions need a supervised bench test.

    
Application updates
Upload a Pi controller .zip bundle built with the supplied update tool. Outputs stop during updates. The Pi checks file hashes and startup health, and restores the previous release on failure. ESP32 .bin files cannot be used.
